# 纯文本交付版式（默认输出格式）

**这是 skill 的默认交付形态**：一份可直接复制投喂的纯文本文档。用户（或 Agent）把每个代码块整段复制进视频模型即可生成，无需任何二次加工。

只有入参 `output_format=json` 时才改按 `schema/output.schema.json` 返回结构化 JSON（供 Agent 程序集成）。

---

## 版式结构（自上而下，缺一不可）

```text
# {角色A} vs {角色B} · {场景短名}（{总时长}s / {shot_style}型 / {目标模型}）

> 生成：duel-fight-prompt v{版本} · MODE={mode} · fight_type={类型} · shot_style={A|B|C}{，降级说明}
> 三层架构：{N} 分镜镜 {总时长}s ⇒ {M} 生成段（{每段时长列表}）
> 节奏曲线：{九段节拍一行概述}

{章节头部：画质风格头 + 场景设定 + 人物详细设定（含触发源句式）+ 全局招式声明 + 音频声明}

{分镜稿：[镜头N] 时长 | 标题 | 运镜组合 + 四段骨架全文}

---

## 生成段 1 / {M} · {时长}s · 分镜{x}-{y}（{戏剧功能}）

**首帧**：{首帧画面描述}
**尾帧**：{尾帧画面描述}

```
{按目标模型方言渲染的正向提示词全文}
```

**负面词**：{负面提示词一行，逗号分隔}

{重复每个生成段}

## 投喂清单

| 段 | 时长 | 分镜 | 戏剧功能 |
|---|---|---|---|
| 1 | {时长}s | {范围} | {功能} |

续接方式：{尾帧接首帧 / 关键帧 / 延长的具体操作建议}
```

## 硬性规则

1. **每个生成段的正向提示词必须放在独立代码块内**，块内不出现 Markdown 标记、镜头编号、时长标注（时长走 params，不进正文）——复制即所得
2. **负面词每个代码块外单独一行**，与正向提示词分开，方便按平台 UI 分别填入
3. 分镜稿保留四段骨架全文（人读/审片/存档），但投喂只需复制生成段代码块
4. 降级与风险标记用 `> ⚠️` 引用行写在标题区，不放代码块内
5. `output_pref=clips` 时可省略分镜稿全文，只留生成段；`output_pref=storyboard` 时可省略生成段（一般不推荐）
6. 纯文本交付下，`meta` 信息（选型理由、默认值回显、log_id）压缩成标题区那几行 `>` 注释

## 与 JSON 模式的关系

| output_format | 交付物 | 适用 |
|---|---|---|
| `text`（默认） | 本版式的纯文本文档，直接复制投喂 | 人用、Agent 转述给人 |
| `json` | `schema/output.schema.json` 结构 | Agent 程序集成、自动化流水线 |
