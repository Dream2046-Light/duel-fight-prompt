# Seedance 2.5 方言（默认主力模型）

**为什么默认选它**：用户样本语料全中文，Seedance 中文理解最强，分镜稿可**不改写直接投喂**，省去翻译导致的镜头术语走味。同时它的多模态参考上限最高（30 图 + 10 视频 + 10 音频）。

---

## 一、硬约束

| 项 | 值 |
|---|---|
| 生成段时长 | 4-30s |
| 分辨率 | 480p / 720p / 1080p（API 仅 480p/720p） |
| 画幅 | 16:9 / 9:16 / 21:9 / 自适应 |
| 提示词长度 | 官方未公开，按 **7000 字符**保守控制 |
| 参考素材 | 最多 30 图 + 10 视频 + 10 音频（flash 版为 10+5+5） |
| 关键帧 | 首尾帧 2 张 |
| 内容过滤 | `content_filter` 参数，默认 true |

> ⚠️ 4K 在规划中但当前不可用。请求 4K 返回 `E_MODEL_UNSUPPORTED`。

---

## 二、提示词语法

Seedance 吃**中文长描述**，结构化叙事。推荐组织顺序：

```
{风格头：8K 3D CG 写实、PBR 物理材质、电影级色彩分级、UE5 Path Tracing、Lumen 全局光照、35mm Kodak 5219 胶片颗粒}

{场景：地点、光线方向、地貌、天气、悬浮粒子、氛围}

{主体A}：{外观、服装、武器}。{特效描述，含触发源}
{主体B}：{同上}

{动作主体：按时间顺序写，明确谁打谁、结果如何}

{运镜：镜头如何运动}

{环境反馈：环境对动作的反应}

{音频描述（audio_mode≠none 时）}
```

### 参考素材绑定

在提示词中用 `@image1`、`@image2` 内联引用上传的素材：

```
@image1 中的白衣剑客立于潭边，手持三尺青锋，剑身有细密使用划痕。
@image2 中的暗紫巨兽自瀑布后浮现，高约三十丈，鳞甲缝隙渗出黑红血雾。
```

**素材角色分配要在提示词开头声明清楚**，一个素材只承担一个角色（形象 / 场景 / 动作参考）。

## 三、打斗场景写法要点

### 1. 动作要按时间顺序铺开，不要堆叠

```
❌ 沈青梧使出五连斩，顾停云格挡，两人激烈交战，水花四溅
✅ 沈青梧斜撩，顾停云以剑格挡；沈青梧顺势横削，顾停云侧闪；沈青梧直刺，
   顾停云踏前斩反制。三招一气呵成，墨金与青白粒子在碰撞点炸开。
```

### 2. 运镜用中文描述 + 保留英文术语

```
镜头高速跟拍沈青梧奔跑轨迹，中段极速 Whip Pan 甩向飞出的长枪，
最后越肩视角跟随裴砚继续冲向巨兽。
```

### 3. 碰撞配方照抄，不要改写

三级碰撞的配方字符串是固定句式，精确复制（见 `../references/03-collision-system.md`）。

### 4. 特效必须绑触发源

```
✅ 墨金飞白死死贴附在剑身、剑格、指节上跳跃、爬行、缠绕，从剑格触发源向外扩散
❌ 墨金特效环绕角色，气势惊人
```

## 四、音频写法

| audio_mode | 写法 |
|---|---|
| `none` | 结尾加：`全程无背景音乐，无字幕，无水印，纯画面输出。` |
| `sfx_only`（默认） | 结尾加：`无背景音乐，无字幕，无水印。保留环境音与打斗音效：瀑布轰鸣、兵刃碰撞脆响、剑气破空、水花炸开、能量爆鸣。` |
| `full` | 另加对白：`沈青梧说"来。"，顾停云答"风，起。"` |

---

## 五、负面词（中文）

```
畸形肢体，多余手指，关节反折，身体穿模，武器穿模，面部崩坏，
动作卡顿，帧间跳变，人物瞬移，场景闪烁，文字，字幕，水印，logo，
低画质，过度模糊，现代建筑，现代服装
```

按 `violence_level` 追加：

| 级别 | 追加 |
|---|---|
| `none` | 血迹，伤口，血雾 |
| `cinematic` | 断肢，内脏，写实血腥 |
| `stylized_blood` | 断肢，内脏，骨骼外露 |

## 六、示例（生成段 prompt）

```
8K 3D CG 写实，超精致3D建模人物，PBR物理材质，电影级色彩分级，UE5 Path Tracing，
Lumen全局光照，35mm Kodak 5219胶片颗粒，色彩空间Rec.2020。

巨型瀑布深潭，光线从上方偏左硬朗射入，穿过水幕形成冷白光束，黑色苔岩环抱深潭，
水雾终年不散，白色花瓣贴水飘动。

@image1 沈青梧：三尺青锋长剑，剑身细密使用划痕，剑格旧铜。墨金飞白死死贴附在剑身、
剑格、指节、衣摆边缘跳跃、爬行、缠绕，从剑格触发源向外扩散，含动态模糊与粒子拖尾。
@image2 顾停云：窄直长剑，护手有风纹。青白风刃死死贴附在剑身、护腕、肩甲上爬行缠绕，
风丝从护腕与剑格喷出。

沈青梧斜撩，顾停云以剑格挡；沈青梧顺势横削，顾停云侧闪；沈青梧直刺，顾停云踏前斩反制。
镜头高速跟拍剑路，中段极速 Whip Pan 甩摇，末段螺旋环绕两人。三招一气呵成，
墨金与青白粒子在碰撞点炸开。轻碰撞：水墨黑白冲击帧+0.05s抽帧+局部负片+
镜头轴向微甩+属性粒子飞溅。

潭面水花炸成环，水雾升腾，瀑布水幕被剑气切出缺口，白色花瓣粉碎。

无背景音乐，无字幕，无水印。保留环境音与打斗音效：瀑布轰鸣、兵刃碰撞脆响、
剑气破空、水花炸开。
```
