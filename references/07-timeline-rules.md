# 07 · 节奏曲线与生成段重组算法

---

## 一、九段式节奏曲线（默认 30s / 15-17 镜）

这是从 10 份样本里提炼出的通用打斗节奏骨架。**不是死模板**，可按题材微调，但"被压制"和"有来有回"两节不可删除。

| # | 节拍 | 镜数 | 时长占比 | 内容 | 碰撞等级 |
|---|---|---|---|---|---|
| 1 | 起手 | 2 | ~13% | 远距离站位、气势对峙、零帧起手 | 无 / 轻 |
| 2 | 试探 | 2 | ~13% | 第一次交手，互相测速，招式简单 | 轻 |
| 3 | 连招升级 | 4 | ~27% | 主角展开连击（五连/七连/九连斩），招式密度最高 | 轻×多次 |
| 4 | 第一次重击 | 1 | ~7% | 跃起重劈，兵刃重撞，全场第一次强冲击 | **重** |
| 5 | 对手反击 | 2 | ~13% | 反派反攻，主角首次受挫 | 轻 / 重 |
| 6 | 主角被压制 | 1 | ~7% | 主角单膝跪地/被连续突刺，最低谷 | 轻×多次 |
| 7 | 大招蓄力 | 1 | ~7% | 时间流速骤降，双方各自凝聚能量 | 无 |
| 8 | 终极对撞 | 2 | ~13% | 大招互轰，全屏冲击帧 | **大招** |
| 9 | 收尾 | 2 | ~13% | 阶梯式拉远，能量消散，收剑定格 | 无 |

**合计**：15-17 镜，28-30s。

### 题材微调

| 题材 | 调整 |
|---|---|
| 巨兽搏斗 | 节拍 3 改为"远距离投掷+命中"，节拍 6 改为"巨兽暴走反击"，主角被压制改为"被巨爪拍飞" |
| 仙侠斗法 | 节拍 7-8 可扩展为双大招（各 2 镜），总镜数到 18 |
| 冷兵器 | 严格按上表，节拍 3 的连击数是节奏核心 |

### 硬性约束

- **节拍 6 不可删** —— 主角必须至少被压制一次，否则违反"有来有回"铁律
- **节拍 4 与节拍 8 必须是重碰撞 / 大招** —— 节奏张力的支点
- 单镜时长 1.0-3.0s；重碰撞与大招给 2.0-2.5s，其余给 1.5-2.0s

## 二、时长分配

### 分镜镜时长（shot）

| 镜头性质 | 时长 |
|---|---|
| 起手、站位、过渡 | 1.5-2.0s |
| 常规连招 | 1.5-2.0s |
| 重碰撞 | 2.0-2.5s |
| 大招爆发 | 2.0-2.5s |
| 蓄力、定格 | 1.5-2.0s |

### 生成段时长（clip）

`生成段时长 = 合并的分镜镜时长之和`，然后**向上取整**到模型支持的整数秒。

| 目标模型 | 合法区间 | 步进 |
|---|---|---|
| Seedance 2.5 | 4-30s | 1s |
| Kling 4.0 | 3-30s | 1s |
| Kling 4.0 Flash | 3-20s | 1s |
| MiniMax H3 | 4-15s | 1s（整数秒） |

**默认天花板 15s**（H3 上限）。需要更长必须显式声明 `allow_long_clip: true`，且此时目标模型不能是 H3。

## 三、生成段重组算法

### 可切点（Cut Point）

一个分镜镜**结尾**满足以下任一条件，即为可切点：

1. **碰撞瞬间** —— 重碰撞或大招爆发的命中帧
2. **定格** —— 全屏定格、时间停滞
3. **收招** —— 招式完成、双方分开、姿态复位
4. **场景切换** —— 空间位置发生实质变化
5. **能量爆发峰值** —— 冲击波扩散到最大的那一帧

轻碰撞**不是**可切点（动作还在连续中）。

### 重组规则

```
输入：分镜镜列表 shots[]，每镜含 duration、is_cut_point
输出：生成段列表 clips[]

1. 从 shots[0] 开始累积当前段
2. 逐镜加入当前段：
   - 段内镜数达到 4 → 强制切段
   - 遇到可切点 且 累计时长 ≥ 模型下限 → 切段
   - 累计时长 ≥ 模型上限 → 必须切段（优先在最近的非可切点前找可切点）
3. 切段时：时长向上取整到整数秒，记录 shot_range
4. 段数不足 2 镜时，与后段合并（违反 shots_per_clip 下限则报 WARN）
```

### 镜间衔接

合并进同一段的相邻分镜镜之间，**必须**用运镜过渡词衔接，禁止硬切：

| 过渡类型 | 衔接词 |
|---|---|
| 快速转场 | 极速 Whip Pan 甩摇至… |
| 穿越遮挡 | 穿过水花/碎石/墨幕入画 |
| 视线引导 | 镜头跟随剑路甩向… |
| 时间变化 | 时间流速骤降，粒子悬停 |
| 空间跳跃 | 镜头猛沉跟随重劈，撞击瞬间猛甩回弹 |

### 反例

```
❌ 分镜3：沈青梧斜撩 → 分镜4：顾停云踏前斩   （硬切，无过渡）
✅ 分镜3：沈青梧斜撩，镜头高频甩摇跟随剑路 → 甩向顾停云，分镜4：顾停云踏前斩拆招
```

## 四、续镜（continuation）衔接

多轮调用拼接长打斗时：

1. 上一段最后一生成段的**尾帧描述**，作为本段第一生成段的**首帧描述**
2. `continuation.character_state` 决定角色开场姿态（伤势、武器是否在手、位置）
3. `continuation.move_progress` 决定从节奏曲线的哪一节切入
4. `continuation.unresolved_action` 必须在本段前 2 镜内接续完毕

**输出时必须在 `clips[0].keyframes[0]` 写明首帧描述**，供 Agent 做尾帧接首帧。
