# 00 · 三层架构与四段骨架

本文件是结构基石。所有输出必须满足此文件的定义。

---

## 一、三层架构

```
章节 sequence   28-30s 完整打斗（用户想要的一场戏）
  └─ 生成段 clip   4-15s，真正投喂视频模型的单元
       └─ 分镜镜 shot  1.0-3.0s，脚本层，保留四段骨架
```

| 层 | 时长 | 作用 | 谁消费 |
|---|---|---|---|
| sequence 章节 | 23.5-30s | 一场完整打斗，有起承转合 | 人（导演/审片） |
| clip 生成段 | 4-15s（按模型） | 模型能消化的物理单元 | 视频模型 |
| shot 分镜镜 | 1.0-3.0s | 导演语言，一个动作节拍 | 人 + 重组器 |

**为什么必须三层**：视频模型单段下限 3-4 秒（MiniMax H3 最低 4s），而分镜语言的镜头是 1.5-2 秒一个刀光。直接喂 1.5s 的镜，模型要么动作做不完，要么自己乱补。

**三层不可混用**：`clips[].prompt` 里不得出现 1.5s 这种低于模型下限的时长声明；`storyboard` 里不得出现 8s 这种超长镜头。

## 二、章节头部结构

```
{画质风格头}

场景设定：{场景描述，含光线方向、地貌、天气、悬浮粒子、氛围}

人物详细设定：
【{角色A}】{外观/服装/武器}。周身特效：{特效色系与形态}，死死贴附在{触发源清单}上跳跃、爬行、缠绕，从{主触发源}向外扩散，含动态模糊与粒子拖尾。
【{角色B}】{同上}

全招式叠加雾山五行手绘水墨飞白，{A}出{特效A}，{B}出{特效B}；全程强动态模糊+水墨速度线+TimeRamp快慢结合；兵刃与肢体碰撞强制触发三级对应特效（见 03-collision-system）。零站桩无蓄力，{换位频率}，招式密布如暴雨倾盆，绝无原地僵持；每一击必须有命中、格挡、闪避、拆招、反击等明确结果，禁止打空气；对手不能全程挨打，必须有来有回；{音频声明}。
```

### 音频声明三选一

| audio_mode | 写法 |
|---|---|
| `none` | 全程无背景音乐，无字幕，无水印，纯画面输出 |
| `sfx_only`（默认） | 无背景音乐，无字幕，无水印；保留环境音与打斗音效（兵刃碰撞、破空、脚步、水花、能量爆鸣） |
| `full` | 无背景音乐，无字幕，无水印；保留环境音、打斗音效与角色对白 |

### 画质风格头（注意：8K 是风格词，不是输出分辨率）

```
8K 3D CG 写实，超精致3D建模人物，PBR 物理材质，电影级色彩分级，
UE5 Path Tracing，Lumen 全局光照，Nanite 几何精度，
35mm Kodak 5219 胶片颗粒，色彩空间 Rec.2020，
人物皮肤纹理、发丝动态、汗渍/血渍附着超写实，
布料动力学真实，金属兵刃带使用划痕与旧化质感
```

> ⚠️ **必须知晓**：`8K` 与 `60帧` 是渲染风格描述词，不是输出参数。三个目标模型实际最高 4K（仅 Kling 4.0）、H3 固定 24fps。实际输出分辨率由 `output_resolution` 参数控制，不要写进提示词正文去误导模型。

## 三、四段骨架（每个分镜镜必须齐全，顺序固定）

```
[镜头N] {时长} | {标题} | {运镜组合}
【复合运镜】：{镜头运动描述，含起幅-运动-落幅}
【极速动势与拆招】：{动作拆解，谁打谁、怎么打、结果如何}
【锚定特效与碰撞】：{碰撞等级×次数}，{配方}，{特效表现}
【环境反馈】：{环境对动作的反应}
【受击反馈】：{可选，仅反派有反击时}
```

### 各段写法要点

**【复合运镜】** —— 必须有起幅、运动过程、落幅三段式。运镜词从 `04-camera-library.md` 取，每镜 2-3 段运镜，用 `➡️`（A/C 型）或 `⇒`（B 型）连接。

**【极速动势与拆招】** —— 核心段。必须写清：谁发起、什么招式、对方如何应对、最终结果。禁止只写"两人激烈交战"。招式从 `05-move-library.md` 取。

**【锚定特效与碰撞】** —— 格式：`{碰撞等级}×{次数}，{特效描述}，{配方字符串}`。配方必须从 `03-collision-system.md` 精确复制，不许改写数值。

**【环境反馈】** —— 环境必须对动作有反应：水花、碎石、落叶、尘雾、光斑、倒影。从 `06-environment.md` 按地形取。禁止空泛的"周围一片狼藉"。

**【受击反馈】** —— 可选。仅当本镜反派有实质反击时添加，写清反派的姿态、伤势、位移变化。

## 四、镜头标题格式（三型）

| 型 | 格式 | 适用 |
|---|---|---|
| **A 累计时间轴** | `[镜头1] 0.0-2.0s \| 零帧起手：贴地仰拍 ➡️ 越肩视角` | 有台词对白、需要精确时间轴 |
| **B 单片时长** | `[镜头1] 2.0s \| 远距离站位·踢枪起手 \| 大远景CRANE升降拉升 ⇒ 低机位仰拍 ⇒ 螺旋环绕` | 纯动作、高频拆招（**默认推荐**） |
| **C 内联紧凑** | `【镜头1】t0-1.2s\|立枪俯视·全景仰拍【复合运镜】：…` | 要求压缩篇幅 |

**符号规范（强制）**：
- 箭头只用 `➡️`（A/C 型）或 `⇒`（B 型），**禁止** `→`、`->`
- 冒号一律全角 `：`
- 镜头编号只出整数，**禁止** `[镜头3.5]`

## 五、生成段（clip）结构

`clips[]` 中每段的字段：

| 字段 | 说明 |
|---|---|
| `index` | 段序号，从 1 开始 |
| `duration_s` | 生成段时长，整数秒，必须落在目标模型区间内 |
| `shot_range` | 覆盖的分镜镜范围，如 `分镜3-5` |
| `prompt` | 正向提示词，按目标模型方言渲染 |
| `negative` | 负面提示词 |
| `params` | 分辨率/画幅/音频/动态强度/内容过滤 |
| `keyframes` | 关键帧描述，Kling 最多 10 张，其余首尾帧 2 张 |
| `warnings` | 本段级风险标记 |

### 生成段 prompt 的组装顺序

```
{模型方言指令行（如 H3 的首帧对齐指令）}

{压缩版全局头：风格 + 场景 + 两主体特效体系，控制在 60 字以内}

{本分镜内容：按合并的分镜镜顺序写，镜间用运镜过渡词衔接}

{音频描述（audio_mode≠none 时必填）}
```

## 六、输出前自检清单

返回前逐条过，任何一条不过就修：

- [ ] 每个分镜镜四段齐全，顺序正确
- [ ] 镜头编号连续整数，无小数
- [ ] 每个分镜镜时长在 1.0-3.0s
- [ ] 每个生成段时长落在目标模型区间
- [ ] 所有生成段时长之和 = 章节总时长
- [ ] 每镜至少 1 个触发源（贴附/爬行/缠绕/触发源）
- [ ] 碰撞等级出现时，配方字符串精确匹配 `03-collision-system.md`
- [ ] 无禁用词（见 `08-banned-patterns.md`）
- [ ] 符号规范：无 `→`、无半角冒号
- [ ] 有来有回：主角至少被压制一次
- [ ] 无站桩：每 0.3 秒有换位
- [ ] 音频声明与 `audio_mode` 一致
- [ ] `meta.selection_reason` 已填写
