# 03 · 三级碰撞配方表

**本文件是查表文件，不是参考文件。配方字符串必须精确复制，一个数值都不许改。**

碰撞等级一旦确定，后面的配方就是死的。改 `0.05s` 为 `0.5s`、漏掉"局部"负片、把"三层泼墨"写成"两层"，都是硬错误。

---

## 一、判定标准：先定级，再查表

| 等级 | 触发条件 | 典型场景 |
|---|---|---|
| **轻碰撞** | 兵刃相击、拳脚相接、擦身而过、脚步踏碎地面 | 连招中的每一击、格挡、侧闪 |
| **重碰撞** | 全力劈砍被硬接、重击命中、身体被震退、武器砸地 | 第一次重击、被击飞、破防 |
| **大招爆发** | 必杀技释放、能量对轰、全屏冲击 | 终极对撞、变身爆发、万剑齐发 |

**判定口诀**：
- 有"来回"、有"拆招" → 轻
- 有一方"被震退/被击飞/破防" → 重
- 有"全屏/天地/吞没/贯穿"级别的能量 → 大招

---

## 二、配方表

### 轻碰撞

```text
水墨黑白冲击帧+0.05s抽帧+局部负片+镜头轴向微甩+属性粒子飞溅
```

| 要素 | 值 | 说明 |
|---|---|---|
| 冲击帧 | 水墨黑白 | 黑白两色，不是彩色 |
| 抽帧 | **0.05s** | 极短，只顿一下 |
| 负片范围 | **局部** | 只在碰撞点周围 |
| 镜头 | 轴向微甩 | 轻微，不是猛甩 |
| 粒子 | 属性粒子飞溅 | 按角色特效色系 |

### 重碰撞

```text
水墨放射冲击帧+0.1s抽帧+中心负片+镜头猛沉/猛甩回弹+三层泼墨爆炸
```

| 要素 | 值 | 说明 |
|---|---|---|
| 冲击帧 | 水墨**放射** | 从中心向外放射 |
| 抽帧 | **0.1s** | 明显顿挫 |
| 负片范围 | **中心** | 碰撞中心区域 |
| 镜头 | **猛沉 / 猛甩回弹** | 二选一，或先沉后弹 |
| 泼墨 | **三层** | 层数固定 |

### 大招爆发

```text
全屏水墨冲击帧+0.15s抽帧定格+全屏负片闪白+径向剧烈震动+中心鱼眼畸变+环形{色系}冲击波扩散
```

| 要素 | 值 | 说明 |
|---|---|---|
| 冲击帧 | **全屏**水墨 | 铺满画面 |
| 抽帧 | **0.15s** + **定格** | 三者中最长，且要定格 |
| 负片 | **全屏**闪白 | 不是局部 |
| 镜头 | 径向剧烈震动 | 从中心向外震 |
| 畸变 | **中心鱼眼** | 大招专属 |
| 冲击波 | **环形 + 色系** | 色系随角色特效变 |

### 冲击波色系对照

| 角色特效色系 | 冲击波写法 |
|---|---|
| 墨金 | 环形水墨金冲击波扩散 |
| 青白 | 环形青白风刃冲击波扩散 |
| 红白 | 环形红白水墨冲击波扩散 |
| 蓝色水墨 | 环形蓝白水墨冲击波扩散 |
| 暗紫妖气 | 环形暗紫能量冲击波扩散 |
| 灰白 | 环形灰白墨色冲击波扩散 |
| 紫蓝白金 | 环形紫蓝白金粒子冲击波扩散 |

## 三、写法格式

在【锚定特效与碰撞】段中的标准格式：

```
{碰撞等级}×{次数}，{本镜特效表现}，{配方字符串}
```

**示例**：

```text
轻碰撞×3，墨金飞白与青白风刃在碰撞点交织炸开，水墨黑白冲击帧+0.05s抽帧+局部负片+镜头轴向微甩+属性粒子飞溅。

重碰撞×1，三层泼墨爆炸，红白水墨从枪身炸开沿枪身上攀，水墨放射冲击帧+0.1s抽帧+中心负片+镜头猛沉/猛甩回弹+三层泼墨爆炸。

大招爆发！全屏水墨冲击帧+0.15s抽帧定格+全屏负片闪白+径向剧烈震动+中心鱼眼畸变+环形水墨金冲击波扩散。重碰撞×1。
```

### 注意

- 大招爆发常与重碰撞叠加出现（大招本身的物理碰撞仍是重碰撞），此时两个都写
- 次数必须与实际拆招次数一致，写了 `轻碰撞×5` 就要在【极速动势与拆招】里真有 5 次接触
- **无碰撞的镜头**（起手、蓄力、收尾）写"无碰撞"，不要硬凑

## 三之补、合法变体（只允许"追加"，不允许"改写"）

核心配方字符串必须原样保留，但**允许在配方末尾追加该角色的种族/属性特效**：

```text
✅ 允许：水墨放射冲击帧+0.1s抽帧+中心负片+镜头猛沉/猛甩回弹+三层泼墨爆炸+紫色能量流体炸开
✅ 允许：全屏水墨冲击帧+0.15s抽帧定格+全屏负片闪白+径向剧烈震动+中心鱼眼畸变+环形水墨金冲击波扩散+紫色电弧全屏跳跃
```

**判定规则**：用"核心配方是完整子串"来判断，追加内容不影响通过。

**常见真实缺陷（校验器会判 FAIL）**：

| 缺陷写法 | 问题 |
|---|---|
| `轴向微甩` | 漏"镜头"二字，应为 `镜头轴向微甩` |
| `放射冲击帧+0.1s抽帧` | 漏"水墨"前缀，应为 `水墨放射冲击帧` |
| `镜头猛沉回弹` | 漏"猛甩"，应为 `镜头猛沉/猛甩回弹` |
| `三层水墨粒子爆炸` | 改写配方，应为 `三层泼墨爆炸`（追加才是对的） |

## 四、英文稿写法（Kling / H3）

技术词保留，数值不改：

```text
Light collision: ink black-white impact frame + 0.05s frame extraction +
local negative + axial micro-shake + attribute particle spray.

Heavy collision: radial ink impact frame + 0.1s frame extraction + center
negative + camera hard drop / whip rebound + three-layer ink splash explosion.

Ultimate burst: full-screen ink impact frame + 0.15s freeze-frame extraction +
full-screen negative flash + radial violent shake + center fisheye distortion +
ring-shaped {color} shockwave expansion.
```

## 五、常见错误

| 错误 | 正确 |
|---|---|
| `0.5s抽帧` | `0.05s抽帧` |
| `水墨冲击帧`（没说黑白还是放射） | `水墨黑白冲击帧` / `水墨放射冲击帧` |
| 大招漏掉鱼眼畸变 | 大招必须含 `中心鱼眼畸变` |
| 重碰撞写"两层泼墨" | 固定 `三层泼墨爆炸` |
| 轻碰撞写"全屏负片" | 轻碰撞只能是 `局部负片` |
