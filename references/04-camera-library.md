# 04 · 运镜词库（中英对照）

运镜按**功能分五档**。每个镜头从"起幅档 → 运动档 → 落幅档"各取一个词组合，形成 2-3 段运镜。

**铁律**：运镜必须服务于动作，不能为炫而炫。碰撞瞬间用"暴击档"，过渡用"加速档"，收尾用"收束档"。

---

## 一、五档运镜表

### 第 1 档 · 交代（Establishing）

用于开场与空间关系建立。

| 中文 | 英文 | 说明 |

| 大远景 CRANE 升降拉升 | Crane shot, high-angle pull-back | 升降机位拉远，交代全景 |
| 超级大远景 | Extreme wide shot | 比大远景更远，强调渺小 |
| 卫星级超广角 | Satellite ultra-wide | 天地尽收，用于终极对撞后 |
| 低机位仰拍 | Low-angle shot | 略低机位，用于走进场景 |

| 中近景环绕 | Medium-close orbit | 近身环绕，用于贴身缠斗 |

## 三、组合规则

### 每镜 2-3 段运镜

```
[起幅] ➡️ [运动] ➡️ [落幅]
```

**组合逻辑**：档位要有递进或对比，不要同档堆叠。

| 场景 | 推荐组合 |
|---|---|
| 起手对峙 | 大远景CRANE升降拉升 ⇒ 低机位仰拍 ⇒ 螺旋环绕 |
| 首次拔剑 | 贴地仰拍 ⇒ 高速跟拍 ⇒ 螺旋环绕 |
| 连招连击 | 高频甩摇 ⇒ 前景水花遮挡 ⇒ 穿水入画 |
| 重击命中 | 镜头猛沉 ⇒ 猛甩回弹 |
| 大招蓄力 | 螺旋环绕 ⇒ 时间流速骤降 |
| 终极对撞 | 中心鱼眼畸变 ⇒ 全屏定格 |
| 收尾拉远 | 卫星级超广角 ⇒ 阶梯式拉远 ⇒ 大远景CRANE升降拉升 |

### 反例

```
❌ 高速跟拍 ⇒ 高速跟拍 ⇒ 高速跟拍   （同档堆叠，无节奏变化）
❌ 卫星级超广角 ⇒ 越肩视角          （景别跳跃过大，中间缺过渡）
✅ 卫星级超广角 ⇒ 急速拉远 ⇒ 越肩视角 （用急速拉远做过渡）
```

## 四、英文稿写法（Kling / H3）

英文稿中运镜术语**保留英文原词**，且按 H3 官方推荐的三段式描述：

```text
{motion type} + {amplitude} + {speed}
```

**示例**：

```text
A high-speed tracking shot (motion type) follows the blade closely (amplitude),
accelerating through the final strike (speed).

A whip pan (motion type) sweeps across the full width of the frame (amplitude),
executed at extreme speed (speed).
```

## 五、运镜与碰撞的绑定

| 碰撞等级 | 必用运镜 |
|---|---|
| 轻碰撞 | 镜头轴向微甩（配方自带，不另加） |
| 重碰撞 | 镜头猛沉 / 猛甩回弹（配方自带） |
| 大招爆发 | 中心鱼眼畸变 + 径向剧烈震动（配方自带） |

> 配方里已含镜头运动的，不要重复堆叠运镜词。配方外的运镜用于**连接**各个碰撞点。
