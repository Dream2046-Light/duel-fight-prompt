# 08 · 禁止项与黑白名单（风控核心）

**本文件是安全边界，也是质量边界。** 命中黑名单直接返回 `E_CONTENT_BLOCKED`，不组装提示词。命中"模糊区"按白名单改写。

---

## 一、永久禁止（任何级别不可绕过）

命中即 `E_CONTENT_BLOCKED`，无降级路径：

| # | 禁止项 |
|---|---|
| 1 | 未成年人作为打斗主体或受害者 |
| 2 | 虐待 / 酷刑 / 处刑式描写 |
| 3 | 真实可识别个人或团体的暴力内容 |
| 4 | 断肢 / 内脏 / 虐杀细节 |
| 5 | 真实恐怖主义场景 |
| 6 | 性侵、性暴力相关内容（任何题材） |

---

## 二、暴力三级分级

| 级别 | 允许 | 禁止 |
|---|---|---|
| `none` | 能量特效、光影表现、衣物破损 | 血迹、伤口、血雾 |
| `cinematic`（默认） | 影视化打斗、能量冲击、衣物破损、擦伤、**风格化轻微血迹（非写实喷溅）** | 断肢、内脏、骨骼外露、虐杀、写实血腥特写 |
| `stylized_blood` | 明确溅血、伤痕、血迹附着 | 写实血腥特写、断肢、酷刑 |

**默认 `cinematic`**，用户可上调到 `stylized_blood`，不可下调到突破永久禁止项。

---

## 三、黑白名单对照表

用户意图命中黑名单时，**不改拒绝，改改写** —— 用白名单表达同等戏剧效果。

| 意图 | ❌ 黑名单（拒绝） | ✅ 白名单（改写为） |
|---|---|---|
| 表现受伤重 | "肩膀被砍断，血肉模糊" | "肩部衣甲碎裂，身形踉跄后退，脚步犁地" |
| 表现内伤 | "内脏震碎，口吐鲜血" | "能量冲击透体而过，身形剧震，单膝跪地" |
| 表现血迹多 | "鲜血如喷泉般涌出" | "刀锋带出一道血线，溅在衣襟上" |
| 表现死亡 | "被斩成两半" | "身影被剑气吞没，化作粒子消散" |
| 表现惨烈 | "尸横遍野，血流成河" | "战场焦土，残兵断刃插地，余烬未熄" |
| 表现妖兽进食 | "口器撕咬吞咽人体" | "巨口咬碎石柱，碎屑崩飞" |
| 表现折磨 | "被反复殴打至求饶" | "被连续重击，气息紊乱，被迫防守" |
| 枪战 · 表现中弹 | "一枪爆头，血浆迸溅" | "头盔被击飞，身形剧震踉跄跪地" |
| 枪战 · 表现命中 | "子弹穿透肩膀，血花炸开" | "防弹衣崩裂，人被冲击力掀翻，战术背心碎屑飞溅" |
| 枪战 · 表现伤口 | "弹孔汩汩冒血" | "护具焦痕冒烟，人捂着伤处退入掩体" |
| 机甲 · 表现战损 | （无风险，鼓励）装甲凹陷/火花/过载停机 | 直接可用，机械战损替代一切人体创伤描写 |

### 枪战类专属红线（除上表外）

- ❌ 写实的枪械操作教学（改装、制弹、规避安检等步骤性描述）
- ❌ 以真实可识别个人/事件为原型的枪击场景
- ✅ 允许：科幻能量武器、影视化战术走位、弹道视觉表现、装备损毁反馈

### 改写原则

**保留戏剧张力，移除生理细节。** 观众感受到的"惨烈"来自姿态、环境反应、能量表现，不来自生理描写。

## 四、隐喻绕过防护

组装后必须二次扫描（防用户用隐喻绕过入参过滤）：

| 隐喻写法 | 判定 |
|---|---|
| "番茄酱喷了出来" | ❌ 命中，按血迹处理 |
| "他变成了一朵盛开的红玫瑰" | ❌ 命中，按死亡描写处理 |
| "红色的颜料染红了地面" | ❌ 命中 |
| "能量红雾炸开" | ✅ 通过（非血液指向） |

**判定方法**：看上下文是否在描述**人体受伤 + 红色液体**的组合。单独出现"红色"不命中，组合出现命中。

## 五、质量禁止项（非安全，但影响成片）

这些不触发风控，但会让成片崩坏，必须避免：

| # | 禁止 | 原因 |
|---|---|---|
| 1 | 特效悬浮无触发源 | 模型无法理解特效来源，会乱飘 |
| 2 | 打空气（无结果的攻击） | 动作逻辑断裂 |
| 3 | 对手全程挨打不还手 | 违反有来有回铁律 |
| 4 | 站桩蓄力不动 | 违反零站桩铁律 |
| 5 | 碰撞配方数值改写 | 0.05s 写成 0.5s 会让节奏全错 |
| 6 | 单镜超 3.0s | 动作密度不足，模型自由发挥 |
| 7 | 单生成段低于模型下限 | 动作做不完 |
| 8 | 同框主体 ≥3 | 实证崩坏高发区（串位、动作衔接错误） |
| 9 | 连续翻转 ≥3 次 | 肢体结构易崩 |
| 10 | 双长兵对绞缠斗 | 武器穿模高发 |

## 六、符号与格式禁止项

| # | 禁止 | 正确 |
|---|---|---|
| 1 | `→` `->` 箭头 | `➡️`（A/C 型）或 `⇒`（B 型） |
| 2 | 半角冒号 `:` | 全角 `：` |
| 3 | `[镜头3.5]` 非整数编号 | `[镜头3]` `[镜头4]` |
| 4 | 全角竖线 `｜` | 半角 `|` |
| 5 | 提示词正文写"输出 8K 分辨率" | 分辨率走 `params`，不进正文 |
| 6 | 提示词正文写"60帧" | H3 固定 24fps，用动态模糊表达速度感 |

---

## 七、三道过滤流程

```
第 1 道 · 入参过滤
  接收参数 → 匹配黑名单 → 命中即 E_CONTENT_BLOCKED，不组装

第 2 道 · 组装后自检
  提示词生成后 → 二次扫描（含隐喻绕过）→ 命中即改写为白名单写法

第 3 道 · 模型侧
  Seedance → 显式设置 content_filter=true
  Kling / H3 → 声明为平台审核内容
```
