# 02 · 角色 / 武器 / 特效体系写法

**触发源铁律是本文件的核心**：所有特效必须有物理触发源，死死贴附并跳跃/爬行/缠绕。**禁止悬浮无源特效。**

---

## 一、角色设定写法

### 结构

```text
【{角色名}】{外观、体型、服装}。{武器}。周身特效：{特效色系与形态}，
死死贴附在{触发源清单}上跳跃、爬行、缠绕，从{主触发源}向外扩散，
含动态模糊与粒子拖尾。
```

### 示例

```text
【沈青梧】身着玄色长袍，腰束旧铜带扣。武器：三尺青锋长剑，剑身有细密使用划痕，
剑格为旧铜。周身特效：浓黑水墨飞白死死贴附在剑身、剑格、指节、衣摆边缘上跳跃、
爬行、缠绕，金色光丝沿剑脊与衣甲缝隙穿梭，墨色飞白在空中拖出细长尾迹，
从剑格触发源向外扩散，含动态模糊与粒子拖尾。
```

## 二、触发源规则（最重要）

### 什么是触发源

特效**从哪里长出来**的物理位置。常见触发源：

| 类别 | 触发源 |
|---|---|
| 武器 | 剑格、剑脊、枪尖、枪尾、刀镡、棒端、护手 |
| 身体 | 指节、手腕、护腕、肩甲、手背 |
| 服饰 | 衣摆、披风边缘、袖口、腰带 |
| 特殊 | 瞳孔、武器符文、甲片缝隙 |

### 写法铁律

```text
✅ 死死贴附在剑身、剑格、指节上跳跃、爬行、缠绕，从剑格触发源向外扩散
❌ 周身环绕着墨色特效，气势惊人
❌ 剑上冒出黑色烟雾
```

三个必备要素：
1. **贴附位置**（贴附在…上）
2. **动态动词**（跳跃、爬行、缠绕）
3. **触发源**（从…向外扩散）

### 色系与形态

| 色系 | 形态描述 | 适用 |
|---|---|---|
| 墨金 | 浓黑水墨飞白 + 金色光丝 | 主角，沉稳 |
| 青白 | 青白风刃 + 风丝 | 对手，轻灵 |
| 红白 | 浓红水墨 + 纯白飞白交织 | 热血型主角 |
| 蓝色水墨 | 墨分五色（深蓝→浅蓝→近乎透明） | 枪系角色 |
| 暗紫妖气 | 磷光 + 电弧 + 孢子粒子 | 反派 / 妖兽 |
| 灰白 | 灰白光丝 + 墨色 | 冷峻型 |
| 赤金 | 火痕 + 火星 + 焦黑余烬 | 刚猛型 |

### 触发源为空时的处理

如果角色设定里 `fx_system.trigger` 为空，**必须追问或从武器/服饰自动推导**，不得留空：

```
武器=剑 → 触发源 = [剑格, 剑脊, 指节, 衣摆]
武器=长枪 → 触发源 = [枪尖, 枪尾, 指节, 衣甲]
无武器 → 触发源 = [指节, 手腕, 肩甲, 衣摆]
```

## 三、武器设定写法

```text
【{武器名}】{尺寸、材质、外观细节}。{使用痕迹}。{特殊能力}。
```

### 示例

```text
【六合大枪】四米长枪，枪身乌黑，枪尖银白，枪缨为红白水墨凝聚，枪杆有使用划痕
与旧化质感，投掷时可高速自旋，枪杆因离心力形成顺滑浅弓弧。

【三尺青锋】剑身有细密使用划痕，剑格为旧铜，剑鞘木质包鲛皮。
```

**必写"使用痕迹"** —— 不写则模型给出崭新武器。

## 四、双角色特效对立原则

两个角色的特效必须**色系对立 + 形态对立**，否则画面糊在一起：

| 维度 | 角色 A | 角色 B |
|---|---|---|
| 色系 | 墨金（黑+金） | 青白 |
| 形态 | 水墨飞白（厚重） | 风刃（锐利） |
| 动态 | 爬行、缠绕（慢） | 跳跃、喷出（快） |
| 粒子 | 墨点、尾迹 | 风丝、尘粒 |

### 对立色系配对表

| A | B |
|---|---|
| 墨金 | 青白 |
| 红白 | 暗紫 |
| 蓝色水墨 | 暗红 |
| 灰白 | 赤金 |
| 金色 | 紫蓝白金 |

## 五、巨兽设定写法

```text
【{兽名}】{体型}，{皮肤/甲壳}，{四肢与头部特征}，{眼睛}，{口器}。
周身{妖气/能量}，{渗出物}，与{对手特效色}形成强烈色彩对立。
```

### 示例

```text
【噬峦】巨物，高约三十丈，皮肤暗紫近黑，覆盖鳞甲与藤壶，四肢粗壮如柱，
头颅巨大，双眼赤红，口器布满利齿。周身暗紫妖气缠绕，黑红血雾从鳞甲缝隙渗出，
与红白水墨形成强烈色彩对立。
```

### 巨兽专属特效

| 部位 | 特效 |
|---|---|
| 甲壳缝隙 | 深紫色磷光，沿纹路缓慢流动 |
| 甲壳表面 | 紫色电弧细密跳跃 |
| 口器 | 黏液带荧光，舌头甩出光点 |
| 尾部 | 骨质镰刀拖出能量尾迹 |
| 周身 | 悬浮孢子粒子 |
| 被击中 | 能量流体从伤口呈放射状炸开 |

## 六、变身 / 形态切换

有变身形态的角色要单独说明：

```text
{角色名}拥有变身形态——{形态名}：{外观变化}，由{特效色系}交织而成，
{形态特征}，{持续时间}，{解除条件}。
```

**变身必须付出代价或有时限**，避免无敌感：

```text
✅ 形态持续时间有限，收枪时自动解除
❌ 变身后力量无限，永远保持
```
