# 06 · 场景库与环境反馈

**环境反馈铁律**：每个分镜镜的【环境反馈】段必须写环境对动作的**具体反应**，禁止"周围一片狼藉"这类空泛描述。

环境反馈不是装饰 —— 它是让模型理解"动作有多重"的物理线索。重碰撞必须有大范围环境反应，轻碰撞只给局部反应。

---

## 一、场景库

### 1. 巨型瀑布深潭

```
光线从上方偏左硬朗射入，穿过水幕形成冷白光束，潭面碎金反光。地貌为黑色苔岩环抱
深潭，瀑布从百丈悬崖倾泻，水雾终年不散。天气半晴，水汽浓重。悬浮粒子：水雾颗粒、
被风卷起的白色花瓣、碎草叶、悬浮尘粒。氛围苍凉肃杀。风持续吹动崖边野草。
```

### 2. 黄昏细雨竹林

```
黄昏细雨中一片广阔开阔的竹林，略低角度透过竹林望去，冷灰蓝与微弱琥珀色调，
细密斜雨落下，薄雾在竹林间飘移，地面溪流淌过卵石与苔藓，竹叶低垂承雨。
```

### 3. 黄昏废墟庭院

```
断壁残垣间，石板地面龟裂，碎石散落，枯树斜插，风卷沙尘掠过庭院，天空昏黄，
远处残阳如血，光从上方偏右倾泻，硬朗明暗，尘埃悬浮空中，气氛肃杀。
```

### 4. 悬浮废墟

```
断壁残垣悬浮于空中，碎石环绕，枯木斜插，风卷沙尘掠过废墟，天空昏黄，
远处残阳如血，光从上方偏左倾泻，硬朗明暗，尘埃悬浮空中，气氛肃杀。
```

### 5. 海滩

```
灰蓝海水轻拍沙滩，远处海雾弥漫，天空云层厚重，光线冷蓝，海浪带来白色泡沫，
礁石 scattered 在岸边，空气带咸味的水雾。
```

### 6. 苍茫荒野

```
烈日当空，大地焦黑龟裂，远处山脉起伏，沙尘在热浪中翻涌；天边云层翻涌，
阳光如金瀑倾泻；空气被高温扭曲。
```

### 7. 浅水河床 / 桥面

```
浅水河床，鹅卵石缝隙间清水流过，薄雾低浮水面，金色晨光穿透树冠形成长条光柱，
两岸绿树野花，桥面浅灰混凝土，晨光在湿沙上形成金蓝色反光。
```

### 8. 草原

```
夕阳下的广阔草原，野草随风起伏，远处地平线在金光中模糊，空气中有草屑与尘粒
悬浮，天空呈现橙红到淡紫的渐层。
```

## 二、环境反馈元素库（按地形取用）

### 水域类（瀑布 / 深潭 / 溪流 / 海滩 / 河床）

| 强度 | 反馈 |
|---|---|
| 轻 | 潭面涟漪扩散、水花轻溅、水雾微动 |
| 中 | 水花炸成环、水雾升腾、水幕被切出缺口 |
| 重 | 潭面炸起水墙、瀑布倒卷、水雾遮天 |
| 大招 | 瀑布断流 / 倒流、潭水蒸发、水雾全灭 |

### 岩石类（废墟 / 桥面 / 荒野）

| 强度 | 反馈 |
|---|---|
| 轻 | 细小石屑飞溅、表面出现细纹 |
| 中 | 蛛网状裂纹扩散、碎石弹空、石板碎裂 |
| 重 | 岩壁裂开、礁石崩裂、地面炸开环形深坑 |
| 大招 | 断壁残垣被粒子海淹没、岩壁剥落、大地龟裂 |

### 植被类（竹林 / 草原 / 树冠）

| 强度 | 反馈 |
|---|---|
| 轻 | 野草伏倒、竹叶轻颤、花瓣飘落 |
| 中 | 竹叶翻飞、落叶粉碎、枯枝断裂 |
| 重 | 竹干爆裂、竹片飞散、巨树被气浪拔起 |
| 大招 | 竹林被连根拔起大半、植被化为齑粉 |

### 大气类（通用）

| 强度 | 反馈 |
|---|---|
| 轻 | 尘粒被气流扰动、光斑晃动 |
| 中 | 悬浮粒子炸开、雾气被搅成旋涡 |
| 重 | 冲击波推开浓雾、尘埃冲天 |
| 大招 | 天地只剩特效两色、云层被撕开 |

### 光影类（通用）

| 场景 | 反馈 |
|---|---|
| 光束 | 光柱被冲击波扭曲、光束边缘明灭 |
| 倒影 | 水面倒影破碎后重聚、倒影中紫光齐齐亮起 |
| 粒子 | 花瓣被卷入风眼、草屑被染成墨色、尘粒被光穿透 |

## 三、强度匹配规则

**环境反应强度必须与碰撞等级匹配**，这是模型判断动作力度的关键线索：

| 碰撞等级 | 环境反应 |
|---|---|
| 轻碰撞 | 只给 1-2 个局部元素（涟漪、石屑、花瓣） |
| 重碰撞 | 给 3-4 个元素，含一个"大范围"反应（水墙、岩裂、气浪） |
| 大招爆发 | 全环境重构（瀑布断流、天地变色、粒子海） |

**反例**：

```
❌ 重碰撞×1，潭面涟漪扩散，花瓣飘落
   （反应太轻，模型会以为是轻击）

✅ 重碰撞×1，潭面炸起水墙，瀑布倒卷，岩壁裂开，水雾遮天
```

## 四、特效色系与环境色的对比原则

特效颜色必须与场景主色**形成对立**，否则画面糊在一起：

| 场景主色 | 推荐特效色 |
|---|---|
| 瀑布深潭（冷白 / 墨黑） | 墨金、青白、红白 |
| 黄昏废墟（昏黄 / 赭石） | 紫蓝白金、暗红、青蓝 |
| 海滩（灰蓝） | 红白水墨、暗紫妖气 |
| 竹林（冷灰绿） | 灰白墨色、赤金 |
| 荒野（焦黑 / 金） | 蓝白气浪、金色能量 |
| 草原（橙红） | 蓝色粒子、水墨金青 |

---

## 五、同批次不重复原则

同一次生成多个章节时，**场景不得重复**。轮换池：

```
瀑布深潭 → 竹林 → 废墟庭院 → 海滩 → 苍茫荒野 → 悬浮废墟 → 河床桥面 → 草原
```

若用户指定场景，以用户指定为准，但仍需按第四节检查特效色对比。
