# 05 · 招式与拆招套路库

**组织原则**：招式按 `攻 → 防 → 反 → 收` 四段结构组织。每个分镜镜必须落在其中一段，禁止只写"两人激烈交战"。

**结果铁律**：每一击必须有明确结果 —— 命中 / 格挡 / 闪避 / 拆招 / 反击，五选一。

## 六、连招编排模板

### 模板 A：主角压制型（用于节拍 3 连招升级）

```
主角：[起手式] → 五连斩（斜撩/横削/直刺/逆斩/回旋斩）→ 旋身回旋斩
反派：剑格挡 → 侧闪 → 踏前斩拆招 → 横剑格挡 → 后仰避过
结果：轻碰撞×5，双方各退半步，粒子交织成旋涡
```

### 模板 B：反派反击型（用于节拍 5 对手反击）

```
反派：[突进技] → 连续突刺 → 重击
主角：剑鞘格挡 → 错步绕身 → 被击中肩部，身体旋转卸力
结果：轻碰撞×3 + 重碰撞×1，主角首次受挫
```

### 模板 C：巨兽对决型（用于巨兽搏斗）

```
主角：踢枪式 → 拖枪式奔跑 → 标枪投掷（重碰撞）
巨兽：鳞甲碎裂 → 痛吼后退 → 挥爪拍击（重碰撞）
主角：空中侧闪 → 前空翻 → 落到巨兽肩甲
结果：有来有回，主角占主动但巨兽有反击
```

## 七、拳脚搏击（徒手格斗）

### 本类要点

- **打击感来源**：位移 + 卸力 + 环境借力（墙面龟裂、地面尘环、桌椅翻飞）。打击感不依赖任何血腥，肢体碰撞本身即特效
- 碰撞配方照常使用，【锚定特效与碰撞】中的「属性粒子飞溅」换成**拳风涟漪 / 冲击气浪 / 地面尘环**，水系角色可用水雾，火系可用火星
- 触发源句式照常写，源点为：拳锋、指节、脚踝、腰带、腕带

### 攻

| 招式 | 动作描述 | 碰撞 |
|---|---|---|
| 直拳连段 | 刺拳开路 → 摆拳跟进 → 上勾收势，三连一气呵成 | 轻×3 |
| 摆拳 | 大臂横扫，取头部侧面，惯性大 | 轻 |
| 上勾拳 | 自下而上直击下颌，可破抱架 | **重** |
| 肘击 | 近身短打，肘尖砸向胸腹 | 轻 |
| 侧踹 | 直线最强的踢击，可把人踹飞 | **重** |
| 扫踢 | 横扫对方支撑腿，破坏重心 | 轻 |
| 腾空飞膝 | 助跑跃起，膝撞直击胸口，终结技 | **重** |
| 舍身飞踢 | 旋身舍身踢，自身也倒地，险招 | **重** |
| 拳腿连段 | 拳×2 → 扫踢 → 肘击，四连贴身压迫 | 轻×4 |

### 防

| 招式 | 动作描述 |
|---|---|
| 后撤步 | 后滑半步，拳锋擦着鼻尖掠过 |
| 潜避摇闪 | 下蹲摇闪，摆拳从头顶扫过 |
| 拍击格挡 | 以手掌拍开对方手腕，化开线路 |

### 反

| 招式 | 动作描述 | 碰撞 |
|---|---|---|
| 闪身反击 | 摇闪避开直拳，顺势摆拳回击 | 轻 |
| 接腿摔 | 接住对方扫踢，顺势掀翻 | 轻 |
| 组合拳反击 | 格挡后立刻拳×2还击 | 轻×2 |
| 肘膝反制 | 近身缠斗中肘击接膝撞 | 轻×2 |

### 受击表现（cinematic 级：姿态代替血迹）

| 状态 | 描述 |
|---|---|
| 踉跄后退 | 连退数步，脚跟犁地 |
| 卸力旋转 | 被击中后顺势转身卸力，借势拉开距离 |
| 气息紊乱 | 单膝跪地撑地喘息，汗珠甩落 |

## 八、机甲格斗

### 本类要点

- **打击感来源**：吨位。液压、推进器、金属形变、火花。**全程无血液**，受击反馈统一为装甲损伤 —— 装甲碎屑即「属性粒子飞溅」，机械战损本身即特效，天然契合 cinematic 暴力分级
- 触发源句式照常写，源点为：装甲接缝、关节、推进器喷口、胸口反应堆视窗
- 【环境反馈】权重上调：机甲吨位必然改变环境（地面塌陷、楼宇震颤、灯柱折断、玻璃幕墙共振），不许机甲打架地面没反应

| 下砸肘 | 腾空肘击下砸 | **重** |

## 九、现代枪战（受限类，风控最严）

### 本类要点

- **风控红线**：见 `08-banned-patterns.md` 黑白名单第七节 —— **不写人体中弹伤口特写、不写爆头、不写血浆喷溅、不写真实战术教学**。中弹反馈统一改写为「护具崩裂 / 装备脱手 / 掩体碎屑」，戏剧效果由战术动作与弹道表现承担
- 碰撞配方照常使用。枪弹命中的碰撞等级：命中护具/装备 = 轻碰撞（装备损毁为「属性粒子」）；命中掩体被拦 = 无碰撞；剧情重击（近身缴械、爆炸冲击）= 重碰撞
- 触发源句式照常写，源点为：枪口硝烟、抛壳窗、战术手电、消音器
- 快枪节奏适配：单镜内 2-3 个射击节拍 = 轻碰撞×2 / ×3，与拳脚连段同构

### 攻

| 招式 | 动作描述 | 碰撞 |
|---|---|---|
| 掩体间跃进 | 低姿 sprint 到下一个掩体，碎步快而碎 | 轻（脚步） |
| 火力压制 | 三连点射逼对方掩蔽，弹道连成虚线 | 轻×3 |
| 单发快射 | 举枪即射，一发脱离 | 轻 |
| 滑铲突进 | 滑铲穿过低障碍，起身即射 | 轻 |
| 双枪交替 | 左右手交替速射，弹幕交织 | 轻×4 |
| 近身枪斗 | 枪身格挡后抵近速射（弹道只表现冲击，不表现伤口） | 轻 |
| 投掷烟雾/闪光 | 烟雾弹爆开，视野切入白茫茫 | 无 |

### 防

| 招式 | 动作描述 |
|---|---|
| 战术翻滚 | 侧向翻滚规避弹道，起身已换好弹匣 |
| 掩体龟缩 | 整个人缩进掩体，子弹打得掩体碎屑飞溅 |
| 听声辨位 | 依据弹着点判断对方方位 |

### 反

| 招式 | 动作描述 | 碰撞 |
|---|---|---|
| 弹道预知偏折 | 见闻色式闪避：头部微偏，子弹擦过耳际 | 轻（擦过） |
| 掩体反击 | 等对方换弹间隙，起身两发点射 | 轻×2 |
| 火力反击 | 受压制后立刻反压制，双方弹道在空中交错 | 轻×3 |
| 近身缴械 | 突入贴身，打飞对方手中武器 | **重** |

### 收

| 招式 | 动作描述 |
|---|---|
| 验枪收枪 | 枪口垂下，退弹验枪，动作干脆 |
| 垂枪戒备 | 枪口朝下，保持警戒缓慢移动 |

## 十、连招编排模板（新增三类）

### 模板 D：拳脚贴身型（用于节拍 3 连招升级）

```
主角：刺拳试探 → 摆拳跟进 → 对方拍击格挡 → 拳腿连段（拳×2→扫踢→肘击）
反派：后撤步 → 潜避摇闪 → 组合拳反击
结果：轻碰撞×6，拳风涟漪与地面尘环交织，碎裂的水泥块飞溅
```

### 模板 E：机甲吨位型（用于节拍 3-5）

```
主角A：液压直拳 → 盾反冲拳 → 螺旋钻拳（重碰撞）
机甲B：能量护盾格挡 → 侧向喷射闪避 → 肩部浮游炮齐射
主角A：装甲硬吃一梭弹幕，胸甲火花迸溅，半跪过载
结果：轻碰撞×4 + 重碰撞×1 + 环境塌陷（地面龟裂、灯柱折断）
```

### 模板 F：枪战术型（用于节拍 3-5，注意风控红线）

```
主角：掩体间跃进 → 火力压制 → 滑铲突进拉近距离
反派：掩体龟缩，弹着点打得掩体碎屑飞溅 → 战术翻滚换位
主角：近身枪斗（枪身格挡后抵近，装备崩裂为反馈）
反派：弹道预知偏折，反身点射击飞主角武器（重碰撞，缴械收场）
结果：全程无人体伤口描写，戏剧效果由战术走位与弹道视觉承担
```

## 十一、编排禁忌

| ❌ 禁止 | ✅ 正确 |
|---|---|
| 两人激烈交战，招式千变万化 | 写清每一招的名称、顺序、结果 |
| 主角连续十招全部命中 | 反派必须格挡/闪避/反击，有来有回 |
| 反派站着不动挨揍 | 每 0.3 秒换位，击必错步绕身 |
| 大招无前摇瞬发 | 必须有蓄力节拍（时间流速骤降） |
| 同一招连用三次以上 | 同批次不重复，从库里轮换 |
| 枪战中弹特写 / 爆头 / 血浆 | 命中反馈改写为护具崩裂、装备脱手，见 08 黑白名单 |
| 机甲打架地面纹丝不动 | 吨位必改环境：地面塌陷、楼宇震颤、碎屑飞溅 |
| 徒手对打无受击反应 | 每击必有踉跄 / 卸力 / 气息紊乱之一 |
